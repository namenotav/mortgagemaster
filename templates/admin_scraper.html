📊 Data Sources

🏦 Individual Bank Websites
✅ Active (HSBC, Nationwide, Barclays)

Scrapes rates directly from bank websites. May require maintenance if site structures change.

💰 MoneySuperMarket
⚠️ Requires permission

Comparison site with comprehensive data. Check Terms of Service before enabling.

📈 Moneyfacts API
💡 Recommended (requires API key)

Professional mortgage data feed. Most reliable option. Add MONEYFACTS_API_KEY to environment variables.

📊 MoneySavingExpert
🔜 Planned

Expert mortgage guides and rates. Implementation planned for future release.

ℹ️ How Data Scraping Works

  • Automatic Updates: Scraper runs daily at 3 AM to fetch fresh deals
  • Multiple Sources: Data from bank websites, comparison sites, and APIs
  • Validation: All scraped data is validated and deduplicated before saving
  • Fallback: If scraping fails, existing data is preserved
  • Rate Limiting: Built-in delays to respect website policies
