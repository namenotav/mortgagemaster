================================================================================
  HOW TO BACKUP EVERYTHING TO YOUR COMPUTER
================================================================================

You have 3 options (pick the easiest for you):

--------------------------------------------------------------------------------
OPTION 1: Complete Automatic Backup (RECOMMENDED - EASIEST)
--------------------------------------------------------------------------------

Run this ONE command:

    python backup_everything.py

It will:
✅ Backup all your code files
✅ Backup PostgreSQL database (if you provide Railway DATABASE_URL)
✅ Create a complete backup folder with everything

Result: COMPLETE_BACKUP_20250123_143022/ folder with ALL your data

Time: 5 minutes

--------------------------------------------------------------------------------
OPTION 2: Database Only (Quick)
--------------------------------------------------------------------------------

Run:

    python backup_database.py

You'll need:
- Your Railway DATABASE_URL (from Railway dashboard)

Result: backup_20250123_143022/ folder with database JSON files

Time: 2 minutes

--------------------------------------------------------------------------------
OPTION 3: Manual Copy (No scripts needed)
--------------------------------------------------------------------------------

Step 1: Copy this entire folder
    - Copy /home/user/mortgagemaster to USB drive or Desktop

Step 2: Get database from Railway
    - Go to Railway > PostgreSQL > Data tab
    - Export each table to CSV manually

Time: 10 minutes

================================================================================
WHERE TO GET RAILWAY DATABASE_URL
================================================================================

1. Open browser: https://railway.app
2. Login to your account
3. Click on "mortgagemaster" project
4. Click on "PostgreSQL" (the database icon)
5. Click "Variables" tab
6. Find "DATABASE_URL"
7. Click "Copy" button
8. Paste it when the backup script asks

It looks like:
postgresql://postgres:LONG_PASSWORD@containers-us-west-123.railway.app:5432/railway

================================================================================

After backup, you'll have a folder containing:

COMPLETE_BACKUP_20250123_143022/

│   ├── templates/
│   ├── static/

│

Total size: ~10-30 MB (depending on how much data you have)

================================================================================
AFTER BACKUP - KEEP IT SAFE
================================================================================

✅ Copy the backup folder to:
   - USB drive
   - External hard drive
   - Google Drive / Dropbox
   - Another computer

✅ Make backups regularly:
   - Daily if actively developing
   - Weekly if stable

✅ Test your backup:
   - Open the JSON files to verify data is there
   - Check file sizes aren't 0 bytes

DONE! Your work is backed up.

================================================================================
TROUBLESHOOTING
================================================================================

Error: "psycopg2 not installed"
Fix: Run: pip install psycopg2-binary

Error: "Could not connect to database"
Fix: Check DATABASE_URL is correct (copied from Railway exactly)

Error: "Permission denied"
Fix: Run: chmod +x backup_everything.py

Can't run Python scripts?
Fix: Use OPTION 3 (manual copy) - just copy this entire folder
